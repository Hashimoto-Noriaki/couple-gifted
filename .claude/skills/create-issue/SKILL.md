ユーザーの説明をもとに GitHub issue を作成する。

## 手順

1. issue の種別を確認する（バグ報告 / 機能要望 / タスク）
2. タイトルと詳細をユーザーと決める
3. 以下のテンプレートで本文を組み立てる
4. タイトル・本文をコマンド文字列に直接埋め込まない（`"`・`` ` ``・`$()`等が含まれるとコマンドが壊れる、または意図しないシェル展開が発生する）。必ず変数に格納してから`"$変数名"`の形で参照する
   1. 本文をWriteツール等で一時ファイルに書き出す（例: `/tmp/issue-body.md`）
   2. タイトルを変数に入れる: `title="<生成したタイトル>"`
   3. 作成する:
      ```bash
      gh issue create --title "$title" --body-file "$body_file"
      ```

## ラベル

変更内容に応じて `--label` を付与する:
- `bug` — バグ報告
- `enhancement` — 機能要望
- `chore` — 設定・ドキュメント系
